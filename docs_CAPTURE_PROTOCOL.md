# BrandSplats capture protocol v0.1 (Coke sleek 330 ml)

Supplied by Napkin: raised stand ~15 cm, busy background, no turntable, KIRI Featureless Object Scan,
no matte spray, 3 orbit heights (~10°, 30°, 60°), locked WB + exposure, grey card + chart + chrome ball in first frames.

## Checklist
1. Lock focus, exposure, ISO, shutter and white balance (manual). Record values. Same settings for all three orbits.
2. First frames (before the can is placed or beside it, same light): 18% grey card, colour chart (ColorChecker),
   chrome ball. Chrome ball = light probe for relighting; grey card/chart = exposure + WB + colour calibration.
3. Orbits at ~10°, 30°, 60° elevation, same radius, 60-90% overlap, can centred on the stand.
4. Light: one steady, diffuse source; no flicker; note position. Avoid direct window light changing mid-capture.
5. Held-out validation: a separate set of ~10 stills NOT used for reconstruction, plus ≥3 stills under a
   different light position (e.g. flash left/right) with the same chart/ball in frame.
6. Measure can with calipers (body Ø at 3 heights, height, base Ø, lid Ø, neck height) and log them.

## Known risks (not yet validated)
- No turntable + busy background + moving camera: scale is unknown and metal highlights move between frames,
  which breaks multi-view consistency. KIRI's "featureless" mode helps pose but not specular consistency.
- Whether three orbits suffice is UNVALIDATED.
